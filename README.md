# Прогноз недельной инфляции в России (Росстат)

Учебный проект. Карточка с фактом последней недели и прогнозом на две ближайшие недели.

| Неделя | Инфляция |
|---|---|
| 29.09–05.10 (тарифы ЖКХ) | 0,96% |
| 06.10–12.10 | 0,11% |
| 13.10–19.10 | 0,05% |
| 20.10–26.10 | 0,08% |

Годовая инфляция на 26.10.2026: 7,11%.

## Прогноз

| Неделя | Публикация | Прогноз | Факт |
|---|---|---|---|
| 27.10–02.11 | 04.11.2026 | 0,08% | — |
| 03.11–09.11 | 11.11.2026 | 0,08% | — |

Метод: среднее за три последние недели без недели с тарифами. Разброс за эти недели 0,05–0,11%.

## Запуск

Откройте `index.html` в браузере.

После публикации данных Росстата заполните колонку «Факт» и сравните с прогнозом.
